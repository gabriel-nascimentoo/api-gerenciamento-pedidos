# Evidências do Postman

Salve nesta pasta as capturas reais feitas no Postman, com método, URL, corpo (quando houver), resposta e status HTTP visíveis.

Nomes solicitados pelo enunciado:

1. `01-criacao.png` - POST válido em `/pedidos`, resposta 201.
2. `02-validacao.png` - POST inválido em `/pedidos`, resposta 400.
3. `03-listagem.png` - GET `/pedidos`, resposta 200.
4. `04-consulta-inexistente.png` - GET `/pedidos/999999`, resposta 404.
5. `05-atualizacao.png` - PATCH `/pedidos/{{pedidoId}}/status`, resposta 200.

Não há imagens de exemplo nesta pasta porque as capturas devem mostrar a execução real da API no computador do aluno.
